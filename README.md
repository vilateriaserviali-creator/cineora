# CINEORA — рабочая версия

Это первая рабочая версия комнаты CINEORA.

Что уже есть:
- комнаты по коду;
- подключение нескольких пользователей;
- синхронизация Play / Pause / перемотки;
- отображение текущего времени каждого участника;
- список реальных участников без фейковых имён;
- чат в реальном времени;
- отправка эмодзи через кнопку;
- поле для прямой ссылки на видеофайл;
- адаптивный интерфейс.

## Запуск

1. Установить Node.js 18+.
2. В этой папке выполнить:
   npm install
3. Запустить:
   npm start
4. Открыть:
   http://localhost:3000

Для доступа друзей через интернет сервер нужно разместить на хостинге, который поддерживает Node.js и WebSocket/Socket.IO.
