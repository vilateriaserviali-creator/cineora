# CINEORA — рабочая версия

Это первая рабочая версия комнаты CINEORA.

Что уже есть:
- комнаты по коду;
- подключение нескольких пользователей;
- синхронизация Play / Pause / перемотки;
- отображение текущего времени каждого участника;
- список реальных участников без фейковых имён;
- чат в реальном времени;
- отправка эмодзи через кнопку;
- поле для прямой ссылки на видеофайл;
- адаптивный интерфейс.

## Запуск# CINEORA — предложения + обновления сайта

В этой версии:
- предложения пользователей хранятся в PostgreSQL;
- админка `/admin` содержит разделы «Предложения» и «Обновления сайта»;
- администратор может создавать, редактировать, скрывать и удалять обновления;
- опубликованные обновления автоматически появляются на главной странице CINEORA;
- при первом запуске PostgreSQL автоматически создаёт таблицы `suggestions` и `news`.

## Render
1. Подключите Render Postgres к сервису CINEORA через `DATABASE_URL` (Internal Database URL).
2. Добавьте `ADMIN_PASSWORD`.
3. Сделайте Deploy.
4. Откройте `/admin`, введите пароль и перейдите во вкладку «Обновления сайта».

Никакой ручной SQL-команды выполнять не нужно.


1. Установить Node.js 18+.
2. В этой папке выполнить:
   npm install
3. Запустить:
   npm start
4. Открыть:
   http://localhost:3000

Для доступа друзей через интернет сервер нужно разместить на хостинге, который поддерживает Node.js и WebSocket/Socket.IO.
